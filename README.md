# House Prices — прогнозирование стоимости домов

Учебный проект по машинному обучению на основе соревнования
Kaggle House Prices: Advanced Regression Techniques.

Цель проекта — построить модель регрессии, которая по характеристикам
жилого дома прогнозирует его стоимость продажи `SalePrice`.

В проекте последовательно рассматриваются:

- исследовательский анализ данных;
- обработка пропусков;
- feature engineering;
- preprocessing;
- линейные модели;
- K-Nearest Neighbors;
- Decision Tree и Random Forest;
- boosting-модели;
- ансамбли;
- полносвязная нейронная сеть на PyTorch;
- кросс-валидация и сравнение результатов.

## Feature Engineering

В процессе исследования были созданы дополнительные признаки:

- `TotalSF` — суммарная площадь подвала, первого и второго этажей;
- `HouseAge` — возраст дома на момент продажи;
- `RemodAge` — количество лет после последней реконструкции;
- `TotalBathrooms` — общее количество ванных комнат с учётом полных и половинных.

Для части признаков пропуски имеют отдельный смысл и заполняются значениями
`None` или `0`.

Пропуски в `LotFrontage` заполняются медианой по `Neighborhood`.
Если медиана для конкретного района недоступна, используется общая медиана
обучающей выборки.

Для числовых признаков используется заполнение пропусков медианой и
масштабирование `StandardScaler`.

Категориальные признаки кодируются с помощью `OneHotEncoder`.

Для native CatBoost используется отдельный preprocessing без OneHot Encoding,
так как CatBoost умеет работать с категориальными признаками напрямую.

Целевая переменная `SalePrice` перед обучением преобразуется с помощью
`log1p`. Перед созданием Kaggle submission выполняется обратное преобразование
`expm1`.

## Модели основного pipeline

В `main.py` сравниваются следующие модели:

- Linear Regression;
- Ridge;
- Lasso;
- ElasticNet;
- K-Nearest Neighbors;
- Decision Tree;
- Random Forest;
- CatBoost;
- LightGBM;
- XGBoost;
- CatBoost с OneHot Encoding;
- Voting Regressor;
- Voting Regressor из boosting-моделей;
- Stacking Regressor;
- DNN.

Для оценки качества используется `5-fold K-Fold Cross-Validation`.

Основная метрика — `RMSE` для логарифмированной целевой переменной.
Дополнительно рассчитывается `R²`.

## Результаты

Результаты текущего воспроизводимого pipeline:

| Модель | RMSE | R² | STD |
|---|---:|---:|---:|
| CatBoost + OneHot | 0.1224 | 0.9027 | 0.0163 |
| Voting Regressor (Boosting) | 0.1225 | 0.9021 | 0.0173 |
| CatBoost | 0.1226 | 0.9028 | 0.0148 |
| Stacking Regressor | 0.1233 | 0.9013 | 0.0169 |
| XGBoost | 0.1235 | 0.9003 | 0.0176 |
| Voting Regressor | 0.1244 | 0.8973 | 0.0223 |
| LightGBM | 0.1317 | 0.8874 | 0.0169 |
| DNN | 0.1388 | 0.8713 | 0.0256 |
| Lasso | 0.1415 | 0.8566 | 0.0427 |
| ElasticNet | 0.1415 | 0.8565 | 0.0428 |
| Random Forest | 0.1424 | 0.8683 | 0.0184 |
| Ridge | 0.1465 | 0.8486 | 0.0404 |
| Linear Regression | 0.1512 | 0.8400 | 0.0416 |
| KNN | 0.1626 | 0.8331 | 0.0154 |
| Decision Tree | 0.1812 | 0.7901 | 0.0122 |

Лучший результат по основной метрике показал **CatBoost с OneHot Encoding**
со средним RMSE около **0.1224**.

После кросс-валидации эта модель обучается на всей тренировочной выборке
и используется для создания Kaggle submission.

### Результаты исследовательского ноутбука

В ноутбуке проводился подбор гиперпараметров моделей с помощью Optuna,
сравнивались различные варианты ансамблей и исследовались разные настройки DNN.

Также был рассмотрен вариант нейронной сети с Embedding для категориальных
признаков. Он не дал улучшения относительно выбранной DNN, поэтому
в основной pipeline не переносился.

Итоговая DNN использует один скрытый слой из 128 нейронов с функцией
активации ELU, оптимизатор AdamW и `CosineAnnealingLR`.

Средний результат DNN на 5-fold cross-validation:

```text
RMSE = 0.1388
R²   = 0.8713
STD  = 0.0256
```

## Установка

Рекомендуется использовать Python 3.10.

После клонирования репозитория необходимо установить зависимости:

```bash
pip install -r requirements.txt
```

## Запуск проекта

Из корневой папки проекта выполнить:

```bash
python main.py
```

Один запуск выполняет:

1. загрузку `train.csv` и `test.csv`;
2. обработку пропусков;
3. feature engineering;
4. логарифмирование целевой переменной;
5. preprocessing;
6. cross-validation всех моделей;
7. формирование таблицы результатов;
8. обучение финальной модели на всей тренировочной выборке;
9. предсказание для Kaggle test;
10. обратное преобразование прогноза;
11. создание `submission.csv`.

## Выходные файлы

Результаты сравнения моделей сохраняются в:

```text
outputs/results/model_results.csv
```

Файл для отправки на Kaggle сохраняется в:

```text
outputs/submission.csv
```

`submission.csv` содержит две колонки:

```text
Id
SalePrice
```

Во время выполнения проекта также создаётся лог обучения:

```text
outputs/logs/training.log
```

## Конфигурация

Основные параметры проекта вынесены в `config.py`.

Там задаются:

- `RANDOM_STATE`;
- количество folds;
- метрики оценки;
- список моделей;
- параметры линейных моделей;
- параметры KNN, Decision Tree и Random Forest;
- параметры CatBoost, LightGBM и XGBoost;
- параметры ансамблей;
- параметры DNN;
- финальная модель;
- настройки логирования.

Это позволяет изменять основные настройки эксперимента без изменения
логики обучения моделей.

## Воспроизводимость

Для классических моделей используется фиксированный `random_state`.

Для нейронной сети также фиксируются генераторы случайных чисел Python,
NumPy и PyTorch.

Для PyTorch дополнительно используются deterministic algorithms.

Поэтому повторный запуск:

```bash
python main.py
```

в одинаковом окружении воспроизводит результаты cross-validation
и заново создаёт итоговый `submission.csv`.
